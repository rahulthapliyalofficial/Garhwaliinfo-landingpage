# 🏔️ GarhwalInfo — Explore the Root of Garhwal

A premium modern landing page designed to showcase the rich culture, language, heritage, sacred geography, and folklore of Uttarakhand's Garhwal region. Built with high performance, smooth scroll animations, and interactive component architecture.

---

## 🚀 Live Demo & Repository

- **GitHub Repository:** [rahulthapliyalofficial/Garhwaliinfo-landingpage](https://github.com/rahulthapliyalofficial/Garhwaliinfo-landingpage)
- **Live Demo:** https://garhwaliinfo-landingpage-q9tw.vercel.app/

---

## ✨ Key Features

- **Cultural Heritage Showcase:** Tailored sections covering Culture, Heritage, Language, Testimonials, Benefits, and Pricing.
- **Intersection Observer Scroll Reveal:** Custom vanilla JavaScript/React Intersection Observer hooks for high-performance scroll triggers without heavy JS overhead.
- **Fluid & Responsive UI:** Fully responsive layout with custom Tailwind CSS themes, gradients, and subtle animations.
- **Interactive UI Components:** Smooth transitions powered by `framer-motion` and styled utility merging via `clsx` and `tailwind-merge`.

---

## 🛠️ Tech Stack & Dependencies

- **Frontend Framework:** React 19 (`react` & `react-dom` v19.2.6)
- **Language:** TypeScript 5.9
- **Build Tool:** Vite 7.3
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite` v4.1.17)
- **Animations:** Framer Motion v13.0.0
- **Utilities:** `clsx`, `tailwind-merge`, `vite-plugin-singlefile`
